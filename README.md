# 醫療科技競賽選題與設定工具（AI 人機協作升級版）

一個不需登入、無外部付費 API、資料以本地靜態檔保存的繁體中文響應式網頁工具，服務高中生閱讀歷屆醫療科技創意競賽案例、辨識可驗證的問題，並透過「人機協作三階段原則」建立高品質、可驗證之競賽計畫書題目設定。

## 本地啟動

在此資料夾執行任一種靜態伺服器：

```powershell
py -m http.server 4173
```

開啟 <http://localhost:4173>。也可使用 VS Code Live Server 等靜態伺服器；直接雙擊 `index.html` 亦可瀏覽與操作。

## 本次升級重大功能亮點

### 1. 全局字體加大與即時縮放調節
- 全站基礎字體從原本微小的 11–13px 全面放大至舒適易讀的 **18px**（標題最大達 2.4–3.2rem，輸入框 1.05rem）。
- 頂部導覽列新增**即時字級控制器**：
  - `A`：標準字級（16px）
  - `A+`：適中放大（18px，預設舒適值）
  - `A++`：特大展示（20px，適合投影機或高解析度螢幕教學）
  - 選擇結果會自動記錄於瀏覽器 `localStorage`，重新整理後保持偏好。

### 2. 人機協作三階段 AI 企劃輔助專區（Human-in-the-Loop）
在工作坊的每個填寫項目下方，均內建完整的「AI 輔助協作專區」：
- **階段 1【關鍵字發想】：** 學生輸入初步關鍵字或點選標籤，AI（首席教授視角）針對主題痛點、科學原理、高中可行原型與避開銀獎陷阱提供 3 個啟發性方向。
- **階段 2【草稿嚴審優化】：** 學生撰寫一段草稿後，一鍵向 AI（13 所醫學系決審評審視角）提出評鑑，抓出「痛點太模糊」、「缺乏數據」或「宣稱療效取代醫師」等硬傷，並提供金獎規格的修訂版本。
- **階段 3【手動定稿存檔】：** 提供 AI 建議暫存框與「帶入編輯框」按鈕，並常駐**人機協作警示**，嚴格要求學生小組親手對照校內器材、刪除無法驗證的誇大名詞，手動修改定稿。

### 3. 一鍵自動連結 external AI（Gemini, ChatGPT & Claude）
- **⚡ 一鍵複製並開啟 Gemini：** 自動組裝高精度 Prompt 複製到剪貼簿，彈出浮動提示，並直接在新分頁開啟 `https://gemini.google.com/app`。
- **⚡ 一鍵複製並開啟 ChatGPT：** 自動帶入提示詞參數開啟 `https://chatgpt.com/?hints=search&q=...`，若未自動載入亦已預先複製，直接按 `Ctrl+V` (或 `⌘V`) 即可。
- **⚡ 一鍵複製並開啟 Claude：** 自動複製高精度結構化提示詞，並直接在新分頁開啟 `https://claude.ai/new`，貼上即可開始對話。
- **📋 僅複製提示詞 / 👁️ 查看微調提示詞：** 內建抽屜式預覽框，學生可自由微調提示詞再送出。

### 4. 鷹架引導標籤（盡可能不讓學生從零空白苦思）
針對 9 大步驟，預先內建高達 60+ 組高中醫療科技領域的常用情境標籤與經典起手式句型：
- **使用者／場域：** ICU輪班護理師、洗腎中心瘻管患者、居家獨居長者、NICU早產兒團隊等。
- **臨床痛點：** 人工每2小時巡房漏判、侵入式檢測恐懼抗拒、漸進惡化錯失黃金期、管路漏液無即時阻斷等。
- **科學原理：** ESP32微控制器、柔性壓電感測薄膜、NIR光譜濁度分析、Edge AI邊緣運算姿態辨識等。
- **高中可行原型 (POC)：** 離體循環模擬液路、明膠仿生皮膚組織、開源步態影像資料庫訓練等（嚴守高中安全邊界，絕非人體試驗）。
- **量化指標：** 反應延遲 < 1.0秒、AI分類準確率 ≥ 92%、減少工時 60%、原型成本 < 1,500 元等。
- **倫理風險：** 離體模擬無人體試驗、定位為輔助決策不取代醫師、邊緣運算杜絕個資外洩、Fail-Safe 斷電常閉等。

### 5. 動態「銀獎陷阱」預警
- 依據歷屆競賽大數據，選定「精準醫療」賽道或出現前瞻高門檻字眼時，自動跳出琥珀色醒目警示，提醒學生：「精準醫療金獎常從缺，切忌空談奈米/基因，必須規劃高中生能做出的離體驗證原型！」

### 6. 15 頁橫式簡報企劃大綱生成與多重匯出
- 根據官方 115／2026 簡章規定的 **16:9 橫式 PDF 15 頁上限**，將學生的 9 步設定自動轉譯為標準的「15 頁企劃說明書架構 (Markdown)」。
- 支援一鍵複製 15 頁大綱、複製 9 步精簡摘要、匯出 JSON 備份檔、瀏覽器列印為 PDF。
- 提供「🌟 載入金獎示範案例」（以智慧尿袋阻斷IoT裝置為例）與「🗑️ 清空重填」功能。
- 本地 `localStorage` 自動存檔機制，關閉視窗不遺失草稿。

## 檔案結構

- `index.html`：整合字級切換、歷屆案例搜尋、九步工作坊與 2026 參賽規範。
- `styles.css`：全面放大字型、現代化醫療科技視覺配色、AI 協作專區、響應式斷點。
- `app.js`：字級切換、資料持久化、標籤即時帶入、三階段 AI Prompt 組裝、外部 Gemini/ChatGPT 串接、15 頁大綱生成器。
- `data/cases.js`：第2–5屆 76 組官方決賽作品完整收錄與推論。
- `README.md`：本說明文件。

## 參賽簡章規格核對（2026 第六屆）

- **截止日：** 正文 12/24、日程表 12/25（建議以 12/24 提早交件）。
- **展場實作：** 全展區累計至少 3 小時（單日累計 ≥ 3 小時，務必完成簽到/退）。
- **企劃說明書：** 16:9 橫式 PDF，最多 15 頁含封面，≤ 5MB（不符扣 3 分）。
- **創意影片：** ≤ 3 分鐘，解析度 ≥ 1280×720，≤ 100MB（不符扣 3 分）。
- **決審規格：** 5 分鐘口頭簡報 ＋ 5 分鐘現場詢答。
