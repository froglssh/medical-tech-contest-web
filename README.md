# 醫療科技競賽選題與設定工具

一個不需登入、無外部付費 API、資料以本地靜態檔保存的繁體中文響應式網頁小程式，服務高中生閱讀歷屆醫療科技創意競賽案例、辨識可驗證的問題，並建立新題目設定摘要。

## 本地啟動

在此資料夾執行任一種靜態伺服器：

```powershell
py -m http.server 4173
```

開啟 <http://localhost:4173>。也可使用 VS Code Live Server 等靜態伺服器；直接雙擊 `index.html` 通常仍可看頁面，但建議使用 HTTP server 以避免瀏覽器對本地資源的限制。

## 檔案

- `index.html`：三個分頁、案例篩選、工作坊與規則頁。
- `styles.css`：響應式介面與視覺樣式。
- `app.js`：分頁、篩選、九步精靈、摘要複製。
- `data/cases.js`：第2–5屆目前可核對的案例與官方來源 URL。

## 如何新增案例

在 `data/cases.js` 的 `window.CASES` 陣列加入物件：

```js
{e:6, a:'金獎', t:'智慧醫療', n:'官方題名', h:'只寫官方頁或已公開訪談能支持的亮點。', l:'標明教學性借鏡。', r:'寫出仍需驗證的限制，不補造作品全文。', u:'官方 URL'}
```

只使用可核對的官方頁面；若官方只公開題名，亮點、借鏡與風險必須以「依題名的教學性推論」處理，不能寫成評審評語。新增資料後重新啟動／重新整理靜態伺服器即可。

## 測試
