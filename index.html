參賽基本規格

  • 全國公私立高中職在學學生（含自學生）
  • 每隊 3–5 名學生、1–2 名指導教師
  • 可跨校組隊；團隊代表人僅限報名一隊
  • 題目須以台灣醫療科技展展出項目為發想依據
  • 三主題賽道：智慧醫療、精準醫療、全齡健康

致命交件格式（不符扣 3 分）

  • 企劃說明書：16:9 橫式 PDF，最多 15 頁（含封面），檔案 ≤ 5MB；格式不符扣總分 3 分！
  • 創意影片：長度 ≤ 3 分鐘，mp4 / avi / wmv / mov，≤ 100MB，解析度 ≥ 1280×720；逾時扣總分 3 分！
  • 未完成展場 3 小時探索與實作者，喪失參賽資格。

五大評審向度與決審

  • 五向度各佔 20%：創意發想、理論根據、研發規劃、使用情境與效益、創意影片
  • 金／銀／銅獎門檻：90／85／80 分（絕對分數制，未達標準得從缺）
  • 第一階段篩選前 40% 入選；第二階段前 10% 晉級決審
  • 決審包含 5 分鐘口頭簡報與 5 分鐘現場詢答
